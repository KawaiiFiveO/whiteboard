# Simple Whiteboard

A simple whiteboard that supports drawing or storyboarding with a pressure-sensitive pen or mouse. Stabilizer included.

## Shortcuts

| Input | Action |
|---|---|
| `P` / `B` | Pen |
| `E` | Eraser |
| `L` / `A` | Line / Arrow |
| `R` / `O` | Rectangle / Ellipse |
| `T` | Text |
| `F` | Toggle fill |
| `S` | Toggle stabilizer (keeps its level) |
| `[` / `]` | Smaller / larger |
| `Ctrl+Z`, two-finger tap | Undo |
| `Ctrl+Shift+Z` / `Ctrl+Y`, three-finger tap | Redo |
| `←` / `→` | Previous / next panel (storyboard) |
| `N` | New panel (storyboard) |
